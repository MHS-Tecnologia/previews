Class 2 or Class 3, and what it changes

The class on your drawing sets the acceptance criteria IPS inspects to. Class 2 is the default for most industrial and automotive electronics.

Class 3 applies where failure is not an option, in defense, aerospace and life-critical products, and changes solder fill, void and placement limits on the floor. IPS inspects to the class specified and can advise if a drawing is silent.

Cables and harnesses are built to IPC/WHMA-A-620.
